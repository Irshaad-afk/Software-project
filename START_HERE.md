# Getting Started

**Open public app:** https://powerguard-weather-app.vercel.app

**Run locally:** in this folder, `python -m http.server 4173` and visit
http://localhost:4173. Do not double-click `index.html` for a production-like
preview, as browsers may block module imports on `file://` URLs.

**Run tests:** `npm test` (Node.js 20+).

**Moderator page:** `/admin.html`, requires the approved user account.

**Git push:** this repository snapshot includes real Git history based on the
original `Irshaad-afk/Software-project` initial commit. To push, connect or
sign into GitHub as a user with **write** access, then run `git push origin main`
from the extracted project directory, or open the folder in GitHub Desktop
and use **Push origin**. This action has NOT been performed remotely yet.

GitHub base SHA: `5aa7028e16470c78dc1c9b2172cdb865c264299f`.
Avoid force push. If the remote changed meanwhile, fetch and reconcile first.
