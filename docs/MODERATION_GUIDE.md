# Moderator Guide

Moderation exists to maintain trustworthy information, **not** to run a
complaint-resolution helpdesk.

1. Sign in to the account granted the PowerGuard moderator role.
2. Navigate to `/admin.html` and confirm restricted access works.
3. Review community observations for spam, duplicate claims and inaccurate
   location classifications.
4. Check credible external utility notices independently.
5. Dismiss clearly misleading posts or attach a cautious fact-based response.
6. Do not impersonate the provider or claim a community report is an official
   outage confirmation.

Role checks rely on verified server-controlled Supabase app metadata and RLS,
not on hiding moderator UI buttons alone.
